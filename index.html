Linux Installation Documentation

Arch Linux ISO

Download the Arch Linux ISO

VM Setup

Created a new VM, set the disk size to 20GB, added the downloaded ISO, and selected Other Linux 6.x kernel 64-bit.

My first mistake was not giving the VM enough memory. The kernel would not boot until I corrected this.

Connect to the Network

  1. ip link set ens33 up
  2. systemctl restart systemd-networkd
  3. sleep 10
  4. ip addr

I originally had the network set to bridged and had to switch it back to NAT.

Update System Clock

timedatectl set-timezone America/Chicago

Partition and Format Disks

  1. lsblk
  2. fdisk /dev/sda
  3. In fdisk, I entered: o, p, n, pressed Enter three times, then entered a, p, and w.
  4. mkfs.ext4 /dev/sda1
  5. mount /dev/sda1 /mnt
  6. lsblk

I accidentally created a GPT table on my first try.

Install Essential Packages

pacstrap -K /mnt base linux linux-firmware

The installation did not complete at first because my connection was slow. I was using a hotspot. I disabled the download timeout with:

sed -i '/^\[options\]/a DisableDownloadTimeout' /etc/pacman.conf

After that, the installation completed successfully.

Configure the System

  1. genfstab -U /mnt >> /mnt/etc/fstab
  2. arch-chroot /mnt
  3. ln -sf /usr/share/zoneinfo/Area/Location /etc/localtime
  4. hwclock --systohc
  5. locale-gen
  6. nano /etc/locale.gen and remove the # before the en_US.UTF-8 UTF-8 entry.
  7. echo "VicsArchVM" > /etc/hostname
  8. passwd

I had to return to this section after fixing the package installation because I had not been able to enter the installed system with arch-chroot.

Install GRUB and Reboot

  1. grub-install --target=i386-pc /dev/sda
  2. grub-mkconfig -o /boot/grub/grub.cfg
  3. exit
  4. umount -R /mnt
  5. reboot

Post-Installation

Install Desktop Environment

pacman -Syu
pacman -S xorg-server lxqt sddm
systemctl enable sddm
systemctl set-default graphical.target

Create Users

useradd -m -G wheel -s /bin/bash victor
passwd victor
useradd -m -G wheel -s /bin/bash codi
passwd codi
EDITOR=nano visudo

In visudo, I removed the # from %wheel ALL=(ALL:ALL) ALL. Then I switched to victor and checked sudo with:

su victor
sudo whoami

After that, I rebooted and logged in as victor.

Install Zsh and SSH

sudo pacman -S zsh
sudo pacman -S openssh
sudo systemctl enable --now sshd

Terminal Customization

I edited ~/.bashrc and added:

PS1='\[\e[1;32m\]\u@\h\[\e[0m\] \[\e[1;34m\]\w\[\e[0m\] \$ '
alias ls='ls --color=auto'
alias grep='grep --color=auto'
alias diff='diff --color=auto'
alias ip='ip -color=auto'
alias ll='ls -lah'
alias c='clear'
alias ping='ping -c 4'
alias install='sudo pacman -S'

I also enabled the Color option in /etc/pacman.conf and ran source ~/.bashrc.
